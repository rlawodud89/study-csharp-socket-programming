# ch02 과제. 간단한 채팅 서버

- 서버는 여러 클라이언트의 동시 접속을 지원해야 한다.
- 클라이언트는 사용자 이름을 설정할 수 있어야 한다.
- 한 클라이언트가 보낸 메시지는 다른 모든 클라이언트에게 전달되어야 한다.
- 클라이언트 접속/퇴장 시 모든 클라이언트에게 알림이 가야 한다.
- TCP 소켓을 사용해야 한다.

## 서버

- 여러 클라이언트가 접속해야하므로 계속해서 연결 수락을 해야 함
- `Dictionary<Socket, string>`을 사용해 현재 접속 중인 클라이언트 소켓과 이름을 관리
- 각 클라이언트마다 스레드를 실행해서, 각 소켓을 통해 수신받도록 함
- `BroadCast()` 메서드를 정의, Dictionary로 관리 중인 모든 클라이언트에게 데이터 전송

**동작 과정**

1. TCP 소켓 생성하고 로컬 엔드포인트 연결
2. 메인 스레드에서 클라이언트 수락 계속 실행, 수락 시 이름 데이터를 수신받아 Dictionary에 소켓과 함께 저장하고 입장 문구 `BroadCast()`로 모든 클라이언트에게 전송, 클라이언트 스레드 실행
3. 클라이언트 스레드에서는 각 클라이언트에게서 데이터 수신받음, 데이터 수신 받으면 `BroadCast()`를 통해 다른 모든 클라이언트에게 데이터 송신, 해당 클라이언트가 퇴장한 경우 퇴장 문구 `BroadCast()`로 전송

## 클라이언트

- 송신과 수신이 따로 이루어짐 (다른 클라이언트가 데이터를 보내는 것이 언제인지 모름) → 송신과 수신을 각각 스레드로 분리
- 메인 스레드: 데이터 입력받아 서버로 송신
- 수신 스레드: 다른 클라이언트가 서버로 보낸 데이터를 서버로부터 수신받아 출력

**동작 과정**

1. 사용자 이름 입력
2. TCP 소켓 생성하고 서버에 연결
3. 이름 데이터 송신
4. 수신 스레드 생성
5. 메인 스레드에서는 데이터 입력받아 송신, 수신 스레드에서는 서버로부터 오는 데이터 수신
