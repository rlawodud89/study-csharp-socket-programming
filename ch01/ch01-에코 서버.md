# ch01 과제. 에코 서버

- 서버는 클라이언트로부터 받은 메세지를 그대로 돌려보내야 함
- 클라이언트는 사용자 입력을 받아 서버로 전송하고, 서버로부터 받은 응답을 출력해야 함
- 한 번의 통신이 아닌 지속적인 통신이 가능하도록 구현

### 서버

- 클라이언트와 연결되면 데이터를 받아 그대로 클라이언트에게 전송
- 연결된 후 클라이언트가 연결 종료하기 전까지 수신/전송 반복
- 클라리언트와의 연결 종료되어도 서버는 계속 유지, 새로운 클라이언트 연결 기다림

흐름

1. TCP 소켓 생성
2. IP 주소와 포트에 바인딩 (Bind)
3. 연결 대기 상태 (Listen)
4. 연결 수락 (Accept)
5. 클라이언트로부터 데이터 수신(Receive), 수신받은 데이터 그대로 전송(Send)
6. 클라이언트에서 종료한 경우, 수신/전송 루프에서 빠져와 연결 종료(Close) 후, 다시 연결 수락 대기

### 클라이언트

- 에코 서버와 연결한 후, 데이터를 전송하고 응답을 받음
- 종료 문자열 입력한 경우, 연결 종료 및 프로그램 종료

흐름

1. TCP 소켓 생성
2. 서버 IP 주소와 포트로 연결 (Connet)
3. 전송 데이터 사용자로부터 입력 받아 전송(Send)하고, 응답 수신(Receive) 반복
4. 종료 문자열을 입력받으면 전송/수신 루프에서 빠져나와 연결 종료(Close)
