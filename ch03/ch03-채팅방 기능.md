# ch03 과제. 채팅방 기능

- 클라이언트가 `/nick <닉네임>` 명령으로 닉네임을 변경할 수 있어야 한다.
- 클라이언트가 `/join <방이름>` 명령으로 특정 채팅방에 입장할 수 있어야 한다.
- 클라이언트가 `/create <방이름>` 명령으로 새 채팅방을 생성할 수 있어야 한다.
- 클라이언트가 `/list` 명령으로 현재 존재하는 채팅방 목록을 볼 수 있어야 한다.
- 클라이언트가 `/exit` 명령으로 현재 채팅방에서 나갈 수 있어야 한다.
- 채팅방별로 메시지 브로드캐스팅이 이루어져야 한다.

## 서버

- `ChatRoom` 클래스: 각 채팅방 정보 클래스, 채팅방 이름과 소속된 클라이언트 저장
- 각 클라이언트를 담당해 처리하는 `ClientHandler` 클래스에서 현재 소속되어 있는 채팅방 `ChatRoom` 을 멤버로 갖고, 이를 사용해 채팅방 내 인원에게 브로드캐스팅
- 메인 Program에서는 클라이언트(`ClientHandler`)와 채팅방(`ChatRoom`)을 List, Dictionary로 관리
- `/nick <닉네임>` → `ClientHandler` 의 이름 멤버를 새로운 닉네임으로 변경하고, 현재 채팅방 `ChatRoom` 에 소속되어 있는 클라이언트에게 닉네임 변경 메세지 브로드캐스팅
- `/join <방이름>`
    1. 채팅방에 소속되어 있었다면 나가기 (`ClientHandler` 에서 갖고 있던 현재 채팅방 `ChatRoom` 에서 해당 클라이언트 삭제)
    2. 새로운 채팅방에 입장 (Dictionary에서 해당 이름의 `ChatRoom` 접근해 클라이언트 리스트에 추가, `ClientHandler` 에 현재 채팅방을 접근한 `ChatRoom` 으로 변경)
- `/create <방이름>`
    1. 새로운 채팅방 `ChatRoom` 생성하고, 메인 Program의 Dictionary에 추가
    2. 채팅방에 소속되어 있었다면 나가기 (`ClientHandler` 에서 갖고 있던 현재 채팅방 `ChatRoom` 에서 해당 클라이언트 삭제)
    3. 새로운 채팅방에 입장 (생성한  `ChatRoom` 의 클라이언트 리스트에 추가, `ClientHandler` 에 현재 채팅방을 생성한 `ChatRoom` 으로 변경)
- `/list` → 메인 Program에서 Dictionary로 관리하고 있는 모든 `ChatRoom` 에 접근해 정보 가져와서 출력
- `/exit` → `ClientHandler` 에서 갖고 있던 현재 채팅방 `ChatRoom` 에서 해당 클라이언트 삭제
- 일반 메세지 → `ClientHandler` 에서 갖고 있던 현재 채팅방 `ChatRoom` 에 소속되어 있는 클라이언트(클라이언트 리스트에 저장되어 있는 클라이언트)에게 메세지 브로드캐스팅

## 클라이언트

- 서버와 연결 성공하면 메세지 수신 스레드 시작
    - 메인 스레드: 메세지 입력 및 전송 루프
    - 수신 스레드: 서버로부터 메세지 수신 및 출력
- 서버와의 연결이 종료되어 수신받은 데이터의 길이가 0이라면 `isConnected` 가 false가 되어 메인 스레드에서 진행 중이던 메시지 입력 및 전송도 종료
