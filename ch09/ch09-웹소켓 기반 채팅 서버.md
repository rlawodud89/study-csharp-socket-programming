# ch09. 웹소켓 기반 채팅 서버

WebSocket 프로토콜을 사용한 채팅 서버를 구현

- WebSocket 기반 통신 구현
- JSON 메시지 포맷 정의
- ASP.NET Core SignalR 활용
- 간단한 웹 클라이언트 구현

## 서버

- SignalR Hub 수신 → JSON  자동 역직렬화 → 패킷 객체 생성 → 패킷 처리 큐에 추가 → 단일 Worker에서 큐의 패킷 하나씩 처리 → 브로드캐스팅
- `SessionManager` , `PacketQueue` , `PacketHandler` , `WorkerService` : 싱글톤으로 서비스에 추가 → 하나만 실행 유지

**`ChatPacket`** 

- 채팅 패킷 정의 (보낸 사람, 메시지 내용)
- SignalR에서 JSON 직렬화를 자동으로 해주므로 별도의 BinarySerializer로 직렬화하는 메서드는 정의 X

**`ClientSession`** 

- SignalR에서 제공하는 ConnectionId를 저장하여 연결된 특정 클라이언트를 식별

**`SessionManager`** 

- 연결된 세션 관리, 클라이언트 등록 및 해제
- ConnectionId 기준으로 ClientSession을 관리

**`PacketQueue`** 

- 처리할 패킷을 저장해놓는 큐
- 처리 대상 패킷과 해당 패킷을 보낸 세션 정보를 함께 저장

**`WorkerService`**

- 단일 Worker 실행 루프를 구성
- `PacketQueue` 에서 패킷 가져와서 처리하는 무한 루프 실행

**`PacketHandler`** 

- 패킷 처리 메서드 정의
- 처리할 패킷을 받아 다른 클라이언트들에게 패킷 보냄 (브로드캐스팅) → 다른 클라이언트들이 채팅 내용 확인 가능
- `IHubContext<T>` : Hub 외부에서 클라이언트에게 메시지를 보내기 위한 객체
    - DI를 통해 `IHubContext<ChatHub>`를 주입
    - 주입된 객체 사용해 서버에서 모든 클라이언트들에게 패킷 전송 (`Clients.All.SendAsync()`)

**`ChatHub`** 

- 클라이언트 연결 및 수신 담당
- `Hub` 을 상속받아 서버의 WebSocket 엔드포인트 구현 (클라이언트와 직접 통신)
- OnConnectedAsync / OnDisconnectedAsync를 오버라이드 → 클라이언트 연결되면 `SessionManager` 에 등록, 연결 해제되면 `SessionManager` 에서도 등록 해제
- 클라이언트에서 패킷 보내면 `ConnectionId` 로 `SessionManager` 에서 세션 찾고, 패킷과 함께 `PacketQueue` 에 넣음

## 클라이언트

`wwwroot/index.html` 에서 클라이언트 구현

- SignalR JavaScript Client를 사용해서 서버의 Hub(`ChatHub`)와 연결
- 사용자가 입력한 채팅 메시지를 JSON 객체 형태로 전달
- `connection.on()` → 서버가 클라이언트에게 보내는 이벤트 등록
    - 서버가 패킷 보내는 메서드 호출하면 (`Clients.All.SendAsync()`) 클라이언트에서 등록된 콜백 실행
    - 서버에서 받은 채팅 메시지 화면에 출력하는 콜백 등록 → 다른 클라이언트가 보낸 채팅 메시지도 화면에 띄워지도록 함
- `connection.invoke()` → 서버 Hub의 메서드 호출
    - 클라이언트가 전송 버튼 누르면 지정한 메서드(`Send`) 호출
    - Hub(`ChatHub`)에 구현해둔 `Send`가 실행되면서 JSON 객체가 `ChatPacket` 형식으로 패킷 처리 큐에 저장 → Worker Thread에서 꺼내와 처리 → 다른 클라이언트들에게 전송 (브로드캐스
