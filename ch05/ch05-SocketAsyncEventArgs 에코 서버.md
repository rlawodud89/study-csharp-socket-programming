# ch05 과제. SocketAsyncEventArgs 기반 에코 서버

- `SocketAsyncEventArgs` 객체 풀링을 구현한다.
- 공유 버퍼 관리를 위한 `BufferManager`를 구현한다.
- 최대 10,000개의 동시 연결을 처리할 수 있어야 한다.
- 클라이언트 연결/연결 해제 이벤트를 처리한다.
- 성능 측정을 위한 간단한 모니터링 기능을 추가한다. (초당 요청 수, 활성 연결 수)

## 서버

**동작 과정**

1. 서버 초기화
    1. 버퍼 풀(BufferManager) 초기화
    2. 수신용 SAEA 객체 풀 준비: SAEA 객체 생성하고 콜백 함수 지정 및 버퍼 할당 → 수신용 객체 풀에 추가
    3. 송신용 SAEA 객체 풀 준비: SAEA 객체 생성하고 콜백 함수 지정 및 버퍼 할당 → 송신용 객체 풀에 추가
2. 서버 시작: 서버 소켓 생성 및 바인딩, 연결 수락 시작, 모니터링 시작
3. 연결 수락
    1. 연결 수락용 SAEA 객체가 없다면 생성, `AcceptAsync()` 와 SAEA 객체로 연결 수락
    2. 연결 수락 시 지정해둔 콜백 함수 실행 → 수신용 SAEA 객체 풀에서 받아와서 연결된 소켓 저장 후, `ReceiveAsync(readEventArgs)` 로 수신 시작
    3. 연결 루프: 계속해서 연결받기 위해 연결 수락용 SAEA 재사용해서 다시 연결 수락 메서드 실행
4. 수신: 수신용 SAEA 객체의 작업 완료 → 콜백 함수 실행 → 수신 유형으로 판단 → 수신 처리 메서드 실행
    1. 수신된 데이터 SAEA 객체로부터 받아옴
    2. 데이터 처리: 에코 서버이므로 받은 데이터 그대로 송신 (송신 메서드 실행)
    3. 수신 루프: 연결되면서 할당받은 수신용 SAEA 객체 재사용해서 다시 수신 실행 (`ReceiveAsync(readEventArgs)`)
5. 송신: 수신 후 송신 메서드 실행 → 송신용 SAEA 객체 받아서 데이터 처리 → 작업 완료 시 콜백 함수 실행 → 후처리
    1. 풀에서 송신용 SAEA 객체 받음
    2. 송신용 SAEA 객체의 버퍼에 보낼 데이터 복사, 전달할 클라이언트의 소켓 SAEA 객체에 지정
    3. 데이터 전송: 송신용 SAEA 객체 사용해서 전송 실행 (`SendAsync(writeEventArgs)`)
    4. 전송 완료 후 처리 (콜백 함수): 송신용 SAEA 객체 재사용 위해 초기화 후 풀에 반환

**BufferManager**

- 버퍼 풀을 구현한 클래스
- 하나의 버퍼를 세그먼트로 나누고 각 세그먼트를 인덱스로 관리, 할당할 때 세그먼트 단위로 반환
- SAEA 객체에 버퍼 할당, SAEA 객체 없앨 때 BufferManager에 버퍼 반환
- 버퍼 할당할 때 이전에 사용했던 세그먼트(인덱스)가 풀에 있다면 재사용, 아니라면 새 세그먼트(인덱스) 할당

**SocketAsyncEventArgsPool**

- SAEA 객체 풀을 구현한 클래스
- 초기화할 때 사용할 SAEA 객체들을 생성해서 전부 풀에 집어넣음
- SAEA 객체 사용 위해 풀에서 객체를 받고, 다 사용하면 다시 풀로 반환 ⇒ 객체 재사용

**초당 요청 수, 활성 연결 수**

- `_connectedClients` : 현재 연결된 클라이언트 개수
    - 연결 수락할 때마다 +1
- `_requestCount` : 현재 응답 요청받은 개수 = 에코 서버(데이터를 서버로 보내면 그에 대한 응답 받음)이므로 클라이언트에서 데이터를 보낸 개수
    - 수신된 데이터 처리할 때마다 +1
- 서버 시작할 때 모니터링 메서드 비동기로 실행 → 루프 내에서 Delay를 통해 1초 기다렸다가 현재 `_connectedClients` , `_requestCount`  콘솔에 출력, `_requestCount` 초기화

## 클라이언트

- 프로그램을 실행하면 1000개의 클라이언트를 담당하는 비동기 메서드 동시 실행
- 각 메서드에서 클라이언트 생성하고, 자신의 ID를 서버로 보내고 서버로부터 데이터 받는 작업 한번씩 수행
- 이 프로그램을 여러 개 실행함으로써 최대 10000개의 클라이언트까지 서버가 연결을 받아서 데이터를 주고받을 수 있는지 확인 가능
