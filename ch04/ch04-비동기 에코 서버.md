# ch04 과제. 비동기 에코 서버

비동기 소켓을 사용하여 에코 서버와 클라이언트를 구현

- `TcpClient`/`TcpListener` 클래스를 사용한다.
- 서버에서는 `AcceptTcpClientAsync`를 사용하여 비동기적으로 연결을 수락한다.
- 클라이언트 처리는 별도의 작업으로 분리한다.

**서버**

- TCP 소켓을 사용하여 들어오는 연결을 수락한다.
- 클라이언트로부터 받은 모든 메시지를 그대로 다시 전송한다.
- 여러 클라이언트를 동시에 처리할 수 있어야 한다.
- 모든 작업은 비동기적으로 수행한다 (`async/await` 활용).

**클라이언트**

- 서버에 연결하고 사용자 입력을 전송한다.
- 서버로부터 응답을 비동기적으로 수신한다.
- 'exit' 명령어를 입력하면 연결을 종료한다.

## 서버

- `AcceptTcpClientAsync` 을 통해 비동기적으로 클라이언트 연결 수락
- 클라이언트가 연결되면 `await`  중단 벗어나 해당 클라이언트 처리를 담당하는 비동기 메서드 실행
- 각 클라이언트 비동기 메서드는 `await` 없이 실행 → 동시 실행으로 여러 클라이언트 동시에 처리
- 클라이언트 처리 메서드 내에서는 수신받고 송신하는 루프 실행
- 수신을 받으면 `await` 중단 벗어나 받은 데이터를 보내는 로직으로 넘어가도록 해 에코 서버 기능 수행

## 클라이언트

- 실행 시 `ConnectAsync` 으로 서버에 연결, 연결 완료 시 `await` 벗어나면서 송수신 로직으로 넘어감
- 메세지 수신을 담당하는 비동기 메서드를 `await` 없이 실행 → 입력과 전송을 담당하는 메인과 수신 담당 메서드가 동시에 실행 → 송수신 동시 처리
- 메세지 수신 메서드 내 루프: 서버로부터 수신을 받으면 `await` 중단 벗어나 데이터 출력하고, 다시 `await` 수신 로직으로 돌아가 다음 데이터 올 때까지 기다림
- 메인 내 전송 루프: 사용자 입력이 들어오면 서버로 데이터 보냄, 데이터 보내지면 `await` 중단 벗어나 다시 사용자 입력 받음
