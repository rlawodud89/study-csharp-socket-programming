# ch08 과제. 간단한 성능 프로파일러

다음 요구사항을 충족하는 간단한 성능 프로파일러를 구현

- 메서드 실행 시간 측정
- 메모리 사용량 추적
- 결과를 로그 파일로 저장
- 테스트 서버에 적용하여 성능 병목 지점 식별

## 서버

받은 패킷을 그대로 클라이언트에게 전송하는 에코 서버를 테스트 서버로 사용 (ch07에서 만든 네트워크 라이브러리를 기반으로 제작)

- 지정한 코드 구간 실행 시간 및 메모리 사용량 측정
- 수신, 송신, 역직렬화, 패킷 처리(패킷 ID 확인 후 직렬화해 전송) 지점에 대해 테스트 진행
- `PerformanceProfiler` 클래스를 통해 테스트 코드 구간 실행 → 결과 로그 텍스트 파일에 저장

**`PerformanceResult`** 

테스트 결과 데이터 형식 정의

- Name: 테스트한 지점 이름
- ElapsedMilliseconds: 코드 실행 시간
- MemoryUsage: 메모리 사용량
- Time: 측정 종료 시간

**`LogWriter`**

- `PerformanceResult` 를 받아 지정된 로그 파일에 작성
- 로그 파일 경로: 실행 파일이 있는 디렉터리/Log/log.txt
- `PerformanceProfiler` 가 소유해 테스트 결과 나오면 사용

**`PerformanceProfiler`**

- 테스트 코드 구간을 지정해 실행하면 로그 파일에 테스트 결과 출력
    - 수신, 송신, 역직렬화, 패킷 처리(패킷 ID 확인 후 직렬화해 전송) 코드를 각각 `PerformanceProfiler` 를 통해 실행
- 코드 실행 시간: `Stopwatch` 사용
    - 시간 측정 시작 → 코드 실행 → 시간 측정 종료 순으로 진행
    - 측정된 시간으로 확인
- 메모리 사용량: `GC.GetTotalMemory(false)` 사용
    - 실행 전 메모리 사용량 측정 → 코드 실행 → 실행 후 메모리 사용량 측정 순으로 진행
    - 실행 후 사용량 - 실행 전 사용량으로 코드 실행에서 사용된 메모리량 확인

## 클라이언트

- 1~2번 키를 누르면 해당하는 타입의 패킷이 서버로 전달
- 키를 한번 누를 때마다 100개의 동일 타입 패킷을 송신 (테스트 목적)
- 서버로부터 패킷을 받으면 역직렬화로 패킷 타입 확인 → 타입에 맞게 다른 내용 콘솔에 출력
- 패킷 유형, 직렬화/역직렬화 방식 서버와 동일 → 모든 데이터 일관되게 해석
