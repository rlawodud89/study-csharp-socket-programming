# C# Socket Programming Study

이 저장소는 최흥배님의「게임 서버 개발을 위한 C# Socket 프로그래밍」강의를 학습하며 진행한 과제 결과물을 정리한 공간입니다.
각 챕터별로 1개의 과제를 수행하였으며, 구현 코드와 설명을 함께 기록했습니다.

각 챕터의 결과물은 해당 디렉터리(`ch[챕터번호]`)에서 확인할 수 있습니다.
- 소스 코드 (클라이언트 코드 `..._Client.cs`, 서버 코드 `..._Server.cs`)
- 과제 구현 내용 (마크다운 파일)
